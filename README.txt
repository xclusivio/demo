XCLUSIVO STUDIO - SIX PAGE WEBSITE

FILES:
1. index.html   - Home page
2. about.html   - About, approach and audience
3. service.html - Services
4. work.html    - Portfolio
5. process.html - Project process
6. contact.html - FAQ and contact

HOW TO UPLOAD:
Upload all 6 HTML files together into the SAME folder (your website's root folder).
Do not rename the files. Keep index.html as the home page.
Then open https://xclusivo.in/ to visit the website.

All pages share the same styling and navigation. They are standalone HTML files;
you do not need to create CSS or JS folders for this version.
